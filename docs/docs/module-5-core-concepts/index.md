# Module 5: Core Security Concepts & Fundamentals

## Overview

Master the foundational security knowledge essential for every security operations professional. This module covers the threat landscape, adversary behavior, and security frameworks that form the basis of modern SOC operations.

## Learning Outcomes

By the end of this module, you will understand:

- **Threat Landscape**: Current threat actors, motivations, and capabilities
- **Attack Vectors**: Common techniques used by adversaries
- **MITRE ATT&CK**: How to use the framework for defense and detection
- **Security Frameworks**: NIST, ISO 27001, CIS Controls, SOC 2
- **Threat Intelligence**: Sources and how to stay current

## Key Concepts

### The Threat Landscape
- **APTs** (Advanced Persistent Threats) - Nation-state actors
- **Cybercriminals** - Ransomware, data theft, extortion
- **Hacktivists** - Political/social motivation
- **Insider Threats** - Internal risks and data exfiltration

### Common Attack Vectors
- Phishing & Social Engineering
- Exploitation of Vulnerabilities
- Credential Attacks
- Supply Chain Compromise
- Cloud Misconfiguration

### Adversary Frameworks
- **MITRE ATT&CK**: 14 tactics, 150+ techniques
- Helps understand adversary behavior patterns
- Foundation for detection engineering
- Guide for incident response

### Security Frameworks
- **NIST CSF**: 5 core functions (Identify, Protect, Detect, Respond, Recover)
- **ISO 27001**: International standard for ISMS
- **CIS Controls**: Prioritized security actions (IG1, IG2, IG3)
- **SOC 2**: Trust Services Criteria for service providers

## Why This Matters

Understanding the threat landscape and security frameworks allows you to:

1. **Prioritize Defenses** - Focus on threats relevant to your organization
2. **Design Better Controls** - Based on industry best practices
3. **Detect Threats Faster** - Recognize attack patterns
4. **Respond Effectively** - Use proven incident response frameworks
5. **Achieve Compliance** - Meet regulatory requirements
